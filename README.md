## Hey, I'm Alexandre 👋

# Data Analysis · Automation · Operations

*Three years across France, the United States and Spain at Canal+, Air France KLM, and now papernest.*

When I joined my current team, two things struck me.

Callback slots were being opened by feel every week, even though every number needed to size them properly was already sitting in our tables. And when I asked how a metric was calculated, the answer depended on who I happened to ask the question to.

Same problem, twice: the knowledge existed, it just wasn't in a system and it was not governed either. So I started building the systems.

I work in Operation for a contact centre across 4 sites and 8 outsourced partners. The job is about making sure decisions get made on numbers that are actually true. and taking the repetitive work off people's plates, if a task runs the same way every week, it shouldn't need a person to remember it.

### What I've built

- **A weekly slot-opening pipeline**, automated end to end, replacing a manual loop that only worked as long as someone remembered it. Next step is the model that sizes the slots from the data instead of from experience.
- **A WFM data dictionary** with a status model that separates what's been validated from what's only assumed, plus a **Slack assistant** answering from it, so new joiners can ramp up without depending on who's available.
- **A partner performance console**, rebuilt from the SQL up because the existing one couldn't show who was repeatedly off target. Along the way I found a pipeline that had been frozen for eight months without raising a single error.
- **A scheduling engine** for internal training that explains every time slot it turns down.

Full write-ups in [portfolio](https://github.com/AlexandreBurhan/portfolio).
